=====================================================
ডিজিটাল প্রেসক্রিপশন অ্যাপ — ইনস্টলেশন গাইড
=====================================================

এই ফোল্ডারে যা আছে:
  index.html          → অ্যাপের মূল ফাইল
  manifest.json        → অ্যাপের নাম/আইকন/থিম তথ্য
  service-worker.js    → অফলাইনে চালানোর জন্য
  icons/               → অ্যাপ আইকন (192px ও 512px)

--------------------------------------------------
ধাপ ১: ইন্টারনেটে হোস্ট করুন (বিনামূল্যে, Netlify দিয়ে)
--------------------------------------------------
1. https://app.netlify.com/drop এই লিংকে যান (অ্যাকাউন্ট লাগবে, বিনামূল্যে)
2. পুরো ফোল্ডারটি (index.html, manifest.json, service-worker.js, icons/ — সবকিছু একসাথে)
   ব্রাউজারের ঐ বক্সে টেনে (drag & drop) ছেড়ে দিন
3. কয়েক সেকেন্ডে একটি লিংক পাবেন, যেমন:
   https://your-app-name.netlify.app

   (বিকল্প: GitHub Pages, Vercel, Firebase Hosting — যেকোনোটিতেও একইভাবে
   আপলোড করা যায়। শর্ত একটাই: HTTPS হতে হবে, তা না হলে ইনস্টল অপশন আসবে না।)

--------------------------------------------------
ধাপ ২: মোবাইলে ইনস্টল করুন
--------------------------------------------------
Android (Chrome):
  1. উপরের লিংকটি Chrome-এ খুলুন
  2. উপরে-ডানে ৩ ডট মেনু চাপুন
  3. "Install app" বা "Add to Home screen" চাপুন
  4. এখন হোম স্ক্রিনে অ্যাপ আইকন চলে আসবে — সাধারণ অ্যাপের মতোই খুলবে,
     ইন্টারনেট ছাড়াও কাজ করবে

iPhone (Safari):
  1. লিংকটি Safari-তে খুলুন
  2. নিচে/উপরে Share বাটন চাপুন (□ এর ভেতরে ↑ চিহ্ন)
  3. "Add to Home Screen" চাপুন
  4. হোম স্ক্রিনে আইকন যোগ হয়ে যাবে

--------------------------------------------------
গুরুত্বপূর্ণ তথ্য
--------------------------------------------------
- সব ডেটা (ডাক্তারের তথ্য, প্রেসক্রিপশন গ্যালারি) ফোনের নিজস্ব ব্রাউজার
  স্টোরেজে সেভ থাকে (localStorage) — সার্ভারে যায় না, তাই প্রাইভেট।
- ব্রাউজারের ক্যাশ/ডেটা মুছে ফেললে বা অ্যাপ আনইনস্টল করলে প্রেসক্রিপশনগুলোও
  মুছে যাবে। নিয়মিত JPG/PDF ডাউনলোড করে রাখাই নিরাপদ।
- একই লিংক দুই ফোনে খুললে দুই ফোনে আলাদা আলাদা ডেটা থাকবে (একসাথে সিংক হবে না)।

--------------------------------------------------
Google Play Store-এ দিতে চাইলে (ঐচ্ছিক, এককালীন কাজ)
--------------------------------------------------
এই একই কোড দিয়ে আসল APK/AAB বানানো সম্ভব "Capacitor" নামের একটি টুল দিয়ে:

1. কম্পিউটারে Node.js ইনস্টল করুন (nodejs.org)
2. টার্মিনালে:
     npm install -g @capacitor/cli
     npx cap init "প্রেসক্রিপশন" "com.yourname.prescription"
     npx cap add android
3. এই index.html, manifest.json ইত্যাদি ফাইল Capacitor-এর "www" ফোল্ডারে রাখুন
4. Android Studio ইনস্টল করে:
     npx cap open android
   Android Studio খুলে যাবে, সেখান থেকে Build → Generate Signed Bundle/APK
5. তৈরি হওয়া .aab ফাইলটি Google Play Console-এ (এককালীন প্রায় $25 নিবন্ধন ফি)
   আপলোড করে পাবলিশ করুন।

এই ধাপটি টেকনিক্যাল এবং একজন ডেভেলপারের সাহায্য লাগতে পারে। ধাপ ১ ও ২ (PWA)
করলেই বেশিরভাগ ক্ষেত্রে যথেষ্ট — অ্যাপের মতোই আইকন, ফুল স্ক্রিন, অফলাইন
সাপোর্ট সব পাবেন, প্লে স্টোরের ঝামেলা ছাড়াই।
